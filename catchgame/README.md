# Поймай шарики! — Android игра с внутриигровыми покупками

Простая аркада: двигай корзину, лови монеты, избегай бомб.
Скорость растёт со временем. Полная интеграция Google Play Billing.

## Что есть в игре

| Товар (ID в Play Console) | Тип | Эффект |
|---|---|---|
| `continue_token` | Расходуемый | +1 продолжение после проигрыша |
| `golden_basket` | Одноразовый | Золотой скин корзины |
| `double_score` | Одноразовый | Очки ×2 |

Рекорд и состояние сохраняются локально (SharedPreferences, данные никуда не отправляются).

## Как собрать и запустить

1. Установите [Android Studio](https://developer.android.com/studio)
2. **File → Open** → выберите папку проекта → дождитесь синхронизации Gradle
   (если Studio предложит обновить AGP/compileSdk — соглашайтесь)
3. Подключите телефон (включите USB-отладку) или запустите эмулятор → ▶ Run

## Публикация в Google Play (по шагам)

1. **Play Console**: создайте аккаунт разработчика ($25, разово) → «Создать приложение»
2. **Подпишите приложение**: Build → Generate Signed App Bundle → создайте keystore
   (сохраните его и пароли — без них нельзя обновлять приложение!)
3. **Создайте товары**: Monetize → Products → In-app products → добавьте
   `continue_token`, `golden_basket`, `double_score` с ценами → **Активируйте** каждый
4. **Внутреннее тестирование**: создайте трек, добавьте свой Gmail в список тестировщиков,
   загрузите подписанный AAB. Тестовые покупки не списывают деньги!
5. **Data safety** (в Console): заявите «Не собираем данные» — всё хранится на устройстве
6. Заполните описание, иконку 512×512, баннер 1024×500, 2+ скриншота
7. Отправьте на проверку в Production (обычно 1–3 дня)

## Важно

- Покупки работают только через Google Play (нельзя протестировать «в обход»)
- Расходуемые товары потребляются через `consumeAsync`, одноразовые
  подтверждаются через `acknowledgePurchase` — обе вещи уже реализованы
- Не теряйте keystore!
